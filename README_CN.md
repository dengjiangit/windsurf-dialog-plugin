## 🎯 这是什么？

这是一个 **Windsurf IDE 扩展**，解决 AI 对话中途停止的问题。

**核心功能：**
- ✅ AI 每次想结束时，自动弹出确认窗口
- ✅ 你可以选择「继续」并输入新指令
- ✅ 支持上传图片让 AI 分析
- ✅ 自动保存对话历史记录

## 🚀 快速开始

### 1️⃣ 打包扩展
```bash
cd /Users/a0000/work/projects/windsurf-dialog-plugin
./package.sh
```

### 2️⃣ 安装扩展
- 打开 Windsurf
- 按 `Cmd+Shift+P`
- 输入 "Install from VSIX"
- 选择生成的 `.vsix` 文件
- 重启 Windsurf

### 3️⃣ 开始使用
就这么简单！扩展会自动配置，你只需要正常使用 AI 即可。

## ✨ 核心功能

### 🔄 持续对话
AI 不会中途停止，你可以一直让它继续工作。

### 📸 图片支持
- `Ctrl+V` 粘贴图片
- `Ctrl+U` 上传文件
- AI 可以分析图片内容

### 📚 历史记录
自动保存每次对话，按项目分类存储。

### 📊 统计信息
显示累计弹窗次数，了解节省的时间。

## 🔧 配置选项

在 Windsurf 设置中：

```json
{
  "windsurfDialog.historyEnabled": true,
  "windsurfDialog.portRange": {
    "start": 13500,
    "end": 13999
  }
}
```

## 🎨 快捷键

在弹窗中：
- `Ctrl+Enter` - 继续
- `Ctrl+U` - 上传文件
- `Ctrl+V` - 粘贴图片
- `Esc` - 结束

## 🔍 故障排查

### 弹窗没有出现？
1. 检查扩展是否已启用
2. 查看输出面板中的日志
3. 确认 `.windsurfrules` 文件存在
4. 重新加载 Windsurf 窗口

### 端口冲突？
扩展会自动尝试下一个端口，通常无需处理。
